# Neo Form — standalone export

## Запуск на компьютере

1. Установите Node.js 20+ и pnpm.
2. Откройте терминал в корне проекта.
3. Выполните `pnpm install`.
4. Запустите `pnpm dev`.
5. Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Сгенерированные изображения, логотип и Hero-видео уже находятся в `client/public/assets/` и подключены локальными путями.

Форма в этой standalone-версии демонстрационная: для реальной отправки заявок потребуется подключить email, CRM или backend.
